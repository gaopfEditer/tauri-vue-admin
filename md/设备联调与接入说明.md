# 实际设备联调与接入说明

> 依据：`md/设备传感器-功能与操作流程.md`、ApexRp 操作手册、当前代码（已含 Modbus TCP 轮询）

---

## 1. 结论

| 问题 | 答案 |
|------|------|
| 设备会上电后**自动发现**本软件吗？ | **不会**（无主动上报） |
| 本软件会去轮询已配置的设备吗？ | **会**（Modbus TCP 主站，按配置周期读） |
| 怎样才开始轮询？ | 粒子配置填 **真实 IP** + 协议 `ModbusTCP`，重启/`MODBUS_POLL_ENABLED=Y` |
| 联调日志在哪？ | 顶栏 **Debug 图标** / `Ctrl+Shift+D` 弹出面板；完整页「设备轮询联调」；文件 `logs/modbus-poll.log` |

```text
本软件（Master） ──轮询──►  ApexRp（Slave :502）
       │
       ├── 更新 ph_sensor.last_value / com_alarm / flow
       └── 写入联调日志（内存环 + 文件）
```

---

## 2. 现场怎么接

1. ApexRp Setup Tool：静态 IP（与主机同网段），拔掉 SmartPort。  
2. 网线：设备 ↔ 交换机 ↔ 运行主机；`ping` 通，Modbus 端口多为 **502**。  
3. 软件「粒子设备配置」：
   - 协议：`ModbusTCP`
   - **PLC IP = 设备 IP**（必须像 `192.168.1.50`，不要填 `PLC1` 占位）
   - 从机地址：Unit ID，通常 `1`
4. `.env`：`MODBUS_POLL_ENABLED=Y`，`MODBUS_POLL_INTERVAL_SEC=5`
5. 打开顶栏 **局域网图标**（或 `Ctrl+Shift+D`）弹出 Debug 面板看实时日志；出错可自动弹出。完整页：**系统运维 → 设备轮询联调**。

---

## 3. 轮询读什么 / 写什么

| 操作 | 寄存器 | 说明 |
|------|--------|------|
| 读状态 | Holding 40003（addr=2） | RUNNING / SAMPLING / FLOW 等位 |
| 读流量 | Holding 40023（addr=22） | `/100` → L/min 量级 |
| 读通道 | Input 30010–30013 | 拼成 0.5μm / 5.0μm 计数值 |
| ON/OFF | Holding 40002 写 11 / 12 | 软件电源按钮会尝试下发 |

失败时：`com_alarm=1`，`runtime_state=Offline`，ERROR 日志带耗时与原因。

---

## 4. 联调检查清单

```text
① ping 设备 IP
② 设备 Web 或 Modbus Poll 能读 40003
③ 软件配置真实 IP + Unit ID
④ 「设备轮询联调」出现 connect / poll_ok
⑤ 粒子卡片 last_value 变化
⑥ ON → 日志 command 写 40002=11
```

日志级别：`INFO` 成功轮询；`WARN` 跳过（无 IP/占位）；`ERROR` 连接/读失败。

---

## 5. API / 环境变量

| 项 | 说明 |
|----|------|
| `GET /api/device-poll/logs` | 最近轮询日志 |
| `GET /api/device-poll/status` | 开关、周期序号、日志文件路径 |
| `POST /api/device-poll/test` | `{ sensorId }` 单次测通 |
| `POST /api/device-poll/enabled` | `{ enabled }` 启停后台轮询 |
| `MODBUS_POLL_ENABLED` | `Y`/`N` |
| `MODBUS_POLL_INTERVAL_SEC` | 默认 5 |
| `MODBUS_POLL_LOG_DIR` | 默认 `logs` |

---

## 6. 尚未覆盖

- Modbus RTU / 串口、OPC UA  
- 网段自动扫描发现设备  
- 寄存器映射若与具体 ApexRp 固件不一致，需按手册微调地址（改 `modbus_poll.rs`）

**一句话：** 设备不会自己连上来；你配好 IP 后，本软件作为 Master 轮询它，并用页面/文件日志支撑现场联调。
