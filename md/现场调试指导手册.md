# 现场调试指导手册（传感器接入）

> 给现场工程师：装好软件后，按本手册接粒子计数器并确认轮询成功。  
> 关联文档：
> - `md/部署与调试手册.md` — 安装、打包、授权、环境变量
> - `md/设备联调与接入说明.md` — 协议与寄存器说明
> - `md/设备传感器-功能与操作流程.md` — 软件菜单操作细节

**当前现场默认库：SQLite**（无需安装 MySQL）。默认账号：`Admin` / `admin123`（用完请改密）。

## 1. 先装软件、确认能登录

### 1.1 安装

1. 在 **Windows 工控机**上安装安装包（需 WebView2，Win10/11 一般已有）。
2. 启动程序（桌面快捷方式或开始菜单 `soybean-admin`）。
3. 首次运行会自动生成 SQLite：`database/sqlite/field-test.db`（路径以安装目录/工作目录为准）。

### 1.2 登录

1. 账号：`Admin`，密码：`admin123`
2. 若提示授权无效：开发机可确认 `LICENSE_BYPASS=Y`；正式交付走「系统运维 → 授权管理」或 `/license` 激活。

### 1.3 打开 Debug（必开）

- 顶栏 **局域网 / LAN 图标**，或快捷键 **`Ctrl+Shift+D`**
- 面板标题：**运行 Debug 日志**
- 可按来源过滤：`system` / `db` / `modbus`
- 出错默认会自动弹出（面板内可关）

能看到 `db / connect`、`system / api` 之类日志，说明本机 API 与数据库正常。

## 2. 网络与设备侧准备（不接软件也能做）

```text
工控机 ──交换机── ApexRp（粒子计数器）
              │
         静态 IP，如 192.168.1.50
         Modbus TCP :502
```

### 2.1 设备侧（ApexRp）

1. 用 Setup Tool 配 **静态 IP**（与工控机同一网段，例如 `192.168.1.x`）。
2. **拔掉 SmartPort**（若手册要求；避免冲突）。
3. 设备上电，指示灯/面板正常。

### 2.2 工控机侧

1. 本机 IP 与设备同网段（例：`192.168.1.10`）。
2. 命令行：

```bat
ping 192.168.1.50
```

不通：先查网线、交换机、防火墙、IP/掩码，**不要进入软件配置**。

3. （推荐）用 Modbus Poll 连 `192.168.1.50:502`，能读到寄存器再进软件。

> **重要：** 设备**不会**主动连本软件；是软件当 Modbus **主站**去轮询设备。

## 3. 软件里新增 / 配置传感器（两步）

### 3.1 新增设备（轻量建档）

菜单：**设备传感器 → 粒子传感器** → **新增**

填：Custom ID、描述、通道、单位等 → 保存。  
记下列表里的 **传感器 ID**（数字，联调「单次测通」要用）。

### 3.2 配置通讯（关键）

同一行点 **配置**（粒子设备配置弹窗）：

| 字段 | 现场必须填对 |
|------|----------------|
| 协议 | **`ModbusTCP`** |
| PLC IP | **设备真实 IP**，如 `192.168.1.50`（禁止 `PLC1` / 空） |
| 从机地址 | Unit ID，通常 **`1`** |
| 更新间隔 | 可与轮询周期接近（如 5–60 秒） |
| 厂区/房间 | 已在「系统运维 → 厂区组织」建好的节点（可选但建议） |

保存后，后台轮询会在下一周期带上该设备（需 `MODBUS_POLL_ENABLED=Y`，默认已开）。

## 4. 联调：怎么判断已经通了

### 4.1 看 Debug / 联调页

| 入口 | 作用 |
|------|------|
| `Ctrl+Shift+D` | 实时日志 + 启停轮询 + 单次测通 |
| **系统运维 → 设备轮询联调** | 完整联调页 |
| 文件 `logs/modbus-poll.log`、`logs/app.log` | 断电后仍可追溯 |

### 4.2 成功标志（按顺序）

```text
① modbus / connect     连上 IP:502
② modbus / poll_ok    带 status / flow / ch1 / ch2 等
③ 粒子卡片 last_value 更新，Com Alarm 熄灭
④ （可选）点 ON → 日志出现写寄存器 command（40002=11）
```

### 4.3 单次测通（怀疑轮询但想立刻验证）

1. Debug 面板填 **传感器 ID**（库内 `id`，不是 Custom ID）
2. 点 **单次测通**
3. 成功 / 失败都会立刻出一条日志

### 4.4 失败怎么拆

| 日志 / 现象 | 先查什么 |
|-------------|----------|
| `skip` / 占位 IP | PLC IP 是否仍是 `PLC1` 或空 |
| `连接超时` / `connect` ERROR | ping、防火墙、端口 502、设备是否上电 |
| `Modbus 异常码` | Unit ID 是否为 1；固件寄存器是否与软件一致 |
| 卡片 Offline + Com Alarm | 同上；看 `com_alarm` 与 ERROR 详情 |
| 面板完全没 modbus 日志 | 轮询是否暂停；`.env` 里 `MODBUS_POLL_ENABLED`；进程是否真是桌面端 |
| 只有 system/db，没有设备 | 尚未配置任何 `ModbusTCP`+真实 IP 的粒子点 |

## 5. 推荐现场当天流程（一页纸）

```text
□ 1. 安装 exe/msi，登录 Admin/admin123
□ 2. Ctrl+Shift+D，确认有 db/system 日志
□ 3. ping 设备 IP 通
□ 4.（可选）Modbus Poll 读通 :502
□ 5. 厂区组织建好房间节点（如需）
□ 6. 新增粒子点 → 配置：ModbusTCP + 真实 IP + Unit ID=1
□ 7. 等一个轮询周期，或「单次测通」
□ 8. 看到 poll_ok + 卡片数值
□ 9. 试 ON/OFF，看 command 日志
□ 10. 改管理员密码；记录设备 IP / Unit ID / 传感器 ID
□ 11. 正式交付：激活 License，关闭 BYPASS
```

## 6. 环境变量（现场可改）

安装目录旁或项目根 `.env`（以实际部署方式为准）：

```env
DB_DRIVER=sqlite
DB_SQLITE_PATH=database/sqlite/field-test.db

VITE_DESKTOP_API=Y
LICENSE_BYPASS=Y          # 正式现场改为 N
MODBUS_POLL_ENABLED=Y
MODBUS_POLL_INTERVAL_SEC=5
MODBUS_POLL_LOG_DIR=logs
```

重置空库：退出软件 → 删除 `field-test.db` → 再启动（会重新灌种子菜单）。

---

## 7. 多台设备

1. 每台设备各自静态 IP（勿冲突）。
2. 软件里每个点单独「配置」填对应 IP。
3. Debug 日志里用 `host` / `deviceCode` / `#传感器ID` 区分。
4. 周期默认 5s，台数多时可把 `MODBUS_POLL_INTERVAL_SEC` 调大，避免打满设备。

## 9. 常见误区（请先排除）

1. **只用浏览器 `pnpm dev`**：不会起本机 API，现场联调无效；要用桌面端或 `pnpm dev:tauri`。
2. **PLC IP 填 PLC1**：永远不会连真设备。
3. **以为设备会自动发现软件**：不会，必须软件轮询。
4. **单次测通填 Custom ID**：应填数字 **传感器 ID**。
5. **改完配置不看 Debug**：先看日志再猜业务页面。

---

**一句话：** ping 通 → 配真实 IP + ModbusTCP → Debug 出现 `poll_ok` → 卡片有数，即现场接入成功。
