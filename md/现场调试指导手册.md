# 现场调试指导手册（传感器接入）

> 给现场工程师：装好软件后，按本手册接粒子计数器并确认轮询成功。  
> 关联文档：
> - `md/部署与调试手册.md` — 安装、打包、授权、环境变量
> - `md/设备联调与接入说明.md` — 协议与寄存器说明
> - `md/设备传感器-功能与操作流程.md` — 软件菜单操作细节

**当前现场默认库：SQLite**（无需安装 MySQL）。默认账号：`Admin` / `admin123`（用完请改密）。

## 1. 先装软件、确认能登录

### 1.1 安装

1. 在 **Windows 工控机**上安装安装包（需 WebView2，Win10/11 一般已有）。
2. 启动程序（桌面快捷方式或开始菜单 `soybean-admin`）。
3. 首次运行会在本机应用数据目录自动创建 SQLite（约  
   `%AppData%\com.pharmanet.admin\field-test.db`），并内置种子账号。
4. 登录走本机 API `http://127.0.0.1:8080`（不是外网）。若提示「网络不可用」，多半是旧安装包库路径错误——请换用修复后重新打包的版本。

### 1.2 登录

1. 账号：`Admin`，密码：`admin123`
2. 若提示授权无效：开发机可确认 `LICENSE_BYPASS=Y`；正式交付走「系统运维 → 授权管理」或 `/license` 激活。

### 1.3 打开 Debug（必开）

- 顶栏 **局域网 / LAN 图标**，或快捷键 **`Ctrl+Shift+D`**
- 面板标题：**运行 Debug 日志**
- 可按来源过滤：`system` / `db` / `modbus`
- 出错默认会自动弹出（面板内可关）

能看到 `db / connect`、`system / api` 之类日志，说明本机 API 与数据库正常。

## 2. 网络 / 串口准备

### 2.A Modbus TCP（有网口 / 有 IP）

```text
工控机(软件) ──交换机── 粒子仪 IP:502
```

`ping` 通后再进软件，协议选 **ModbusTCP**，PLC IP 填真实 IP。

### 2.B Modbus RTU / RS-485（无 IP，USB 转 485）

```text
工控机 ──USB-485──► 粒子仪 Slave=1
         COM3 19200 8N1  FC04 地址0
```

1. USB-485 插上后确认设备管理器里是 **COM3**（或你的实际口）。  
2. 软件配置：
   - 协议：**ModbusRTU**
   - 串口：`COM3` 或 `COM3@19200`
   - 从机地址：`1`
3. Debug 出现 `RTU ... poll_ok` 即成功；数值进粒子卡片。  

也可用独立脚本验证：`scripts/modbus485_particle_poll.py`（不必再手动跑，软件已内置轮询）。

## 3. 软件里新增 / 配置传感器（两步）

### 3.1 新增设备（轻量建档）

菜单：**设备传感器 → 粒子传感器** → **新增**

填：Custom ID、描述、通道、单位等 → 保存。  
记下列表里的 **传感器 ID**（数字，联调「单次测通」要用）。

### 3.2 配置通讯（关键）

同一行点 **配置**（粒子设备配置弹窗）：

| 字段 | TCP（有 IP） | RTU（USB-485） |
|------|-------------|----------------|
| 协议 | **`ModbusTCP`** | **`ModbusRTU`** |
| PLC IP / 串口 | 真实 IP，如 `192.168.1.50` | `COM3` 或 `COM3@19200` |
| 从机地址 | Unit ID，通常 **`1`** | 同左，通常 **`1`** |
| 更新间隔 | 如 5–60 秒 | 同左 |
| 厂区/房间 | 建议选已建好的节点 | 同左 |

保存后，后台轮询会在下一周期带上该设备（需 `MODBUS_POLL_ENABLED=Y`，默认已开）。

## 4. 联调：怎么判断已经通了

### 4.1 看 Debug / 联调页

| 入口 | 作用 |
|------|------|
| `Ctrl+Shift+D` | 实时日志 + 启停轮询 + 单次测通 |
| **系统运维 → 设备轮询联调** | 完整联调页 |
| 文件 `logs/modbus-poll.log`、`logs/app.log` | 断电后仍可追溯 |

### 4.2 成功标志（按顺序）

```text
TCP：① connect 连上 IP:502  → ② poll_ok（status/flow/ch…）→ ③ 卡片更新
RTU：① connect 打开 COM@波特率 → ② poll_ok（raw u16 + float）→ ③ 卡片更新
```

### 4.3 单次测通（怀疑轮询但想立刻验证）

1. Debug 面板填 **传感器 ID**（库内 `id`，不是 Custom ID）
2. 点 **单次测通**
3. 成功 / 失败都会立刻出一条日志

### 4.4 失败怎么拆

| 日志 / 现象 | 先查什么 |
|-------------|----------|
| `skip` / 占位 IP | PLC IP 是否仍是 `PLC1` 或空 |
| `连接超时` / `connect` ERROR | ping、防火墙、端口 502、设备是否上电 |
| `Modbus 异常码` | Unit ID 是否为 1；固件寄存器是否与软件一致 |
| 卡片 Offline + Com Alarm | 同上；看 `com_alarm` 与 ERROR 详情 |
| 面板完全没 modbus 日志 | 轮询是否暂停；`.env` 里 `MODBUS_POLL_ENABLED`；进程是否真是桌面端 |
| 只有 system/db，没有设备 | 尚未配置 `ModbusTCP`+IP 或 `ModbusRTU`+COM |
| RTU `打开串口` / 权限失败 | COM 口号是否正确；是否被其它程序占用 |
| RTU `CRC 错误` / 超时 | 波特率 19200 8N1、线序/接地、Slave ID |

## 5. 推荐现场当天流程（一页纸）

```text
□ 1. 安装 exe/msi，登录 Admin/admin123
□ 2. Ctrl+Shift+D，确认有 db/system 日志
□ 3A. TCP：ping IP 通；（可选）Modbus Poll 读 :502
□ 3B. RTU：设备管理器确认 COM 口；（可选）Modscan32 / Python 脚本验通
□ 4. 厂区组织建好房间节点（如需）
□ 5. 新增粒子点 → 配置 TCP+IP 或 RTU+COM3@19200，Unit ID=1
□ 6. 等一个轮询周期，或「单次测通」
□ 7. 看到 poll_ok + 卡片数值
□ 8. TCP 可试 ON/OFF；RTU 当前以读数为主
□ 9. 改管理员密码；记录 IP 或 COM / Unit ID / 传感器 ID
□ 10. 正式交付：激活 License，关闭 BYPASS
```

## 6. 环境变量（现场可改）

安装目录旁或项目根 `.env`（以实际部署方式为准）：

```env
DB_DRIVER=sqlite
DB_SQLITE_PATH=database/sqlite/field-test.db

VITE_DESKTOP_API=Y
LICENSE_BYPASS=Y          # 正式现场改为 N
MODBUS_POLL_ENABLED=Y
MODBUS_POLL_INTERVAL_SEC=5
MODBUS_POLL_LOG_DIR=logs
```

重置空库：退出软件 → 删除 `field-test.db` → 再启动（会重新灌种子菜单）。

## 7. 多台设备

1. 每台设备各自静态 IP（勿冲突）。
2. 软件里每个点单独「配置」填对应 IP。
3. Debug 日志里用 `host` / `deviceCode` / `#传感器ID` 区分。
4. 周期默认 5s，台数多时可把 `MODBUS_POLL_INTERVAL_SEC` 调大，避免打满设备。

## 9. 常见误区（请先排除）

1. **只用浏览器 `pnpm dev`**：不会起本机 API，现场联调无效；要用桌面端或 `pnpm dev:tauri`。
2. **PLC IP 填 PLC1**：永远不会连真设备。
3. **以为设备会自动发现软件**：不会，必须软件轮询。
4. **单次测通填 Custom ID**：应填数字 **传感器 ID**。
5. **改完配置不看 Debug**：先看日志再猜业务页面。

---

**一句话：** ping 通 → 配真实 IP + ModbusTCP → Debug 出现 `poll_ok` → 卡片有数，即现场接入成功。
